04
Plugin architecture

Every team can extend the brain safely

Connectorlocal files, Git, BI, wiki, SQL
Extractormetrics, rules, reports, owners
Validatorrequired fields, conflicts, sensitivity
Retrieverkeyword, vector, graph, semantic layer

Plugin output goes to candidate knowledge and human review. Plugins do not publish official truth directly.

05
Offline-first AI

AI accelerates the brain, but does not define it

offline_no_modelYAML, Markdown, rules, keyword retrieval.
local_aiLocal extraction, embeddings, summarization.
hosted_aiApproved provider for richer reasoning.
hybridLocal default, hosted by policy.

The runtime should continue validating, reviewing, and serving approved context even when AI is unavailable.
