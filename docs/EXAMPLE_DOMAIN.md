# Neutral Example Domain

The public demo uses a synthetic product-support scenario. It is intentionally generic and not based on any employer, client, internal dashboard, telecom workflow, finance-planning workflow, or proprietary operating process.

## Domain

```text
support
```

## Primary metric

```text
Incident Resolution Time
```

Definition:

```text
Average elapsed time from incident creation to resolved status for product support cases, excluding duplicate incidents and customer-wait periods.
```

## Supporting objects

```text
Report: SLA Review Dashboard
Rule: SLA Review Window
Owner: Support Operations
Related metrics: First Response Time, Reopen Rate, Ticket Backlog
```

## Demo question

```text
Why did incident resolution time increase?
```

## Why this example is safe

The scenario is common to many generic software-support organizations. It does not reference carrier operations, consumer telecom products, finance planning workflows, company-specific dashboards, internal timing rules, or proprietary metric names.
