# Synthetic Talk2Data Telecommunications Domain Pack

This directory is a public, synthetic reference configuration for testing the Talk2Data Domain Pack and governed-memory contracts. It is not based on an employer, carrier, customer, internal dashboard, or proprietary data source.

Files:

- `domain-pack.yaml` — approved version-one tenant Domain Pack.
- `approved-metric-context.md` — Obsidian note that passes governance promotion.
- `unapproved-draft.md` — structurally valid draft that must not become authoritative memory.

The sample demonstrates telecom concepts without real business data:

```text
wireless
broadband
subscriber
network
retail
customer care
device
market
commercial
```

It also demonstrates the distinction between an unrelated restaurant operating question and an external restaurant or food-delivery signal that is legitimately anchored to telecom retail activations or network congestion.
